# `cns-abstract` 技能

[English](README_EN.md)

Format English abstracts for **Nature / Cell / Science** submissions: punctuation spacing, word limits, and journal-specific narrative cues.

## 适合用它做什么

- 投稿前 Abstract 标点与空格统一
- 对齐三刊词数与叙事习惯
- 整理 PDF 复制产生的硬换行

## 典型请求

- 「按 Nature 150 词限制排版这段 Abstract。」
- 「检查标点后面有没有空格，Cell 投稿用。」

## 你需要提供

- 摘要原文、目标期刊、词数上限（可选）

## 产出

- 排版后摘要 + 修改明细 + 词数统计

## 边界

- 默认不改科学内容；深度润色见 `cns-polishing`

## 相关技能

- `cns-polishing` — 语言与结构润色
- `cns-writing` — 从零起草摘要
