# `cns-abstract` Skill

[中文说明](README.md)

Format English abstracts for **Nature**, **Cell**, and **Science**: punctuation spacing, word limits, and journal narrative cues.

## What To Use It For

- Unify abstract punctuation before submission
- Align word limits and tone across CNS journals
- Fix hard line breaks from PDF copy-paste

## Typical Requests

- “Format this abstract for Nature’s ~150-word limit.”
- “Check spacing after punctuation for a Cell submission.”

## What You Need To Provide

- Abstract text, target journal, optional word cap

## Outputs

- Formatted abstract, change list, word count

## Boundaries

- Does not rewrite scientific content by default; see `cns-polishing`

## Related Skills

- `cns-polishing` — language polish
- `cns-writing` — draft from bullets
