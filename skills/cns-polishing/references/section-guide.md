# 分章节润色要点

## Abstract

- 首句： broad problem + gap 或 central finding
- 无引用；控制词数（Nature ~150, Science ~125, Cell 视子刊）
- 末句避免 hollow significance（「具有重要意义」无内容）

## Introduction

- 漏斗：领域背景 → 具体 gap → 本工作如何填补
- 末段：明确 hypothesis / approach / main finding preview
- Cell 系可略多机制铺垫；Science 系尽早点 significance

## Results

- 按**故事线**非实验时间顺序（除非用户要求保序）
- 每段对应清晰 claim；图引用自然嵌入
- 统计：样本量、重复、检验名可定位

## Discussion

- 不重复 Results 数字
- 机制延伸 ≤ 数据支持；限制诚实
- Nature/Science： broader implication 一段；Cell： mechanism depth

## Title

- Nature/Science：简洁、可读、避免生造缩写
- Cell：可含关键靶点/通路名
- 提供 2–3 备选

## Methods

- 可复现优先；被动/主动按期刊习惯
- 试剂、版本、参数完整；不润色掉可追溯信息
