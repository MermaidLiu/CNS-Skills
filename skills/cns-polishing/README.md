# `cns-polishing` 技能

[English](README_EN.md)

将学术手稿润色、重构或翻译为 **Nature / Cell / Science** 系期刊偏好的英文，保持原意与证据边界。

## 适合用它做什么

- 中文学术段落翻译为投稿级英文
- 精简冗长句、改善论证顺序
- 按目标 CNS 期刊调整摘要、引言、结果、讨论语气
- 收敛 AI 味、夸张声称和过度因果表达

## 典型请求

- 「把这段 Results 改成 Nature 风格，不要改数据。」
- 「Cell 子刊投稿，润色 Abstract 和 Significance。」
- 「Science 风格翻译这段 Introduction。」

## 你需要提供

- 原文、目标期刊（Nature / Cell / Science 或子刊）、章节
- 不可改动的事实、数据、引用
- 期望输出：仅改写稿，或含修改说明

## 产出

- 可粘贴英文改写稿（或中英对照列表）
- 修改说明与需作者确认项

## 边界

- 不新增结果、机制、统计显著性或引用
- 不从零起草整章（见 `cns-writing`）

## 相关技能

- `cns-writing` — 章节起草
- `cns-reviewer` — 预投稿审稿模拟
- `cns-abstract` — 摘要格式与标点专项
