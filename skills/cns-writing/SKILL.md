# CNS 学术写作

基于用户提供的**图件说明、bullet 要点、已有结果**，起草 CNS 风格章节。不编造未提供的数据。

## 工作流

1. 确认目标期刊（Nature / Cell / Science）与章节
2. 读 `../cns-shared/references/journal-profiles.md` + `writing-principles.md`
3. 读 [references/draft-templates.md](references/draft-templates.md)
4. 输出提纲 → 正文草稿 → 证据缺口清单

## 输出结构

- **论证提纲**（列表）
- **章节草稿**（可粘贴）
- **需补充实验/引用**（列表）

## 不应做什么

- 无数据不写 Results 具体数值
- 润色已有段落 → 用 `cns-polishing`
