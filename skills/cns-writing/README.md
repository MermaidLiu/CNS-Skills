# `cns-writing` 技能

[English](README_EN.md)

根据图件与要点起草 **Nature / Cell / Science** 风格章节，重建论证链，不编造数据。

## 适合用它做什么

- 从 bullet 起草 Abstract / Introduction / Discussion
- Cell 系 Significance、Highlights 初稿
- 投稿前论证结构重组

## 典型请求

- 「根据这三张图和要点写 Nature 风格 Abstract。」
- 「帮我搭 Introduction 提纲再写初稿。」

## 你需要提供

- 目标期刊、章节、图件说明或结果要点
- 已有引用（可选）、必须出现的术语

## 产出

- 论证提纲 + 章节草稿 + 证据缺口清单

## 边界

- 不提供未给出的实验数值或引用
- 已有段落润色 → `cns-polishing`

## 相关技能

- `cns-polishing` — 语言润色
- `cns-reviewer` — 预审稿
