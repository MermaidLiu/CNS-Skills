# `cns-writing` Skill

[中文说明](README.md)

Draft **Nature / Cell / Science**-style sections from figures and bullet points, rebuilding the argument chain without inventing data.

## What To Use It For

- Draft abstract, introduction, or discussion from bullets
- Initial Cell-style Significance or Highlights
- Rebuild argument structure before submission

## Typical Requests

- “Draft a Nature-style abstract from these three figures and notes.”
- “Outline and draft the introduction.”

## What You Need To Provide

- Target journal, section, figure captions or result bullets
- Optional references and required terminology

## Outputs

- Argument outline, section draft, and evidence-gap list

## Boundaries

- No fabricated numbers or citations
- Polishing existing prose → `cns-polishing`

## Related Skills

- `cns-polishing` — language polish
- `cns-reviewer` — pre-submission review
