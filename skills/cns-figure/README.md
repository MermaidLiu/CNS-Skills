# `cns-figure` 技能

[English](README_EN.md)

Review or plan **Nature / Cell / Science**-aligned figure layout, panel labels, color-blind safety, and legend statistics.

## 适合用它做什么

- 投稿前 figure checklist
- 多 panel 排版与图注统计句
- 色盲友好与分辨率建议

## 典型请求

- 「按 Cell 标准审查 Figure 2 布局和 legend。」
- 「这组 WB 定量图图注该怎么写统计？」

## 你需要提供

- 目标期刊、图类型、现有图描述或 legend 草稿

## 产出

- 修改清单 + legend draft + 可选绘图代码方向

## 边界

- 不伪造图像；不代做 Photoshop/Illustrator 操作

## 相关技能

- `cns-polishing` — legend 英文润色
- `cns-reviewer` — 图件审稿意见
