# `cns-figure` Skill

[中文说明](README.md)

Review or plan figure layout, legends, and statistics for **Nature**, **Cell**, and **Science** submissions.

## What To Use It For

- Pre-submission figure checklist
- Multi-panel layout and statistical legend wording
- Color-blind-safe and resolution guidance

## Typical Requests

- “Review Figure 2 layout and legend for a Cell submission.”
- “How should I phrase statistics in this WB quant legend?”

## What You Need To Provide

- Target journal, figure type, description or draft legend

## Outputs

- Fix list, legend draft, optional plotting code hints

## Boundaries

- No fabricated images; no hands-on design software work

## Related Skills

- `cns-polishing` — polish legend English
- `cns-reviewer` — mock review including figures
