# CNS 学术写作核心原则

## 1. 失败模式诊断（优先于润色）

| 症状 | 诊断 | 处理 |
|------|------|------|
| 段首无主题句 | 结构问题 | 重写段首，非只改词 |
| 结果与讨论混杂 | 章节错位 | 拆分或标注需作者确认 |
| 因果超出数据 | 声称越界 | 降调为 suggest / is consistent with |
| 术语不一致 | 编辑问题 | 统一全文 |
| 冗长从句链 | 可读性 | 拆句；一句一功能 |

## 2. 伦理边界

- 不新增数据、图表、引用、p 值
- 不改变科学结论方向（升调/降调需标注）
- 翻译时保留不确定性与限定词（may, likely, appears）

## 3. 输出格式约定

- 改写稿可直接粘贴
- 重大结构调整附 **修改说明** 列表（不用宽表格承载长文本）
- 含 `<` `>` 的统计符号用反引号或空格：`p < 0.05`
