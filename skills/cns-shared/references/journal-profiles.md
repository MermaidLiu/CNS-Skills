# CNS 期刊写作画像

Agent 在用户指定目标期刊时，加载对应小节；未指定时默认 `generic-cns`（三刊共通高影响力风格）。

---

## Nature 系

| 项目 | 要点 |
|------|------|
| 代表期刊 | *Nature*, *Nature Communications*, *Nature Methods* |
| 叙事 |  broad interest；首段即阐明 general significance |
| 语气 | 简洁、克制；避免过度 mechanistic 细节堆在 Abstract |
| Abstract | ~150 words，无引用，单段为主 |
| 标题 | 陈述句或问题句；避免缩写堆砌 |
| 图 | 主文 4–6 图常见；Extended Data 分离 |

## Cell 系

| 项目 | 要点 |
|------|------|
| 代表期刊 | *Cell*, *Molecular Cell*, *Cell Reports*, *Cancer Cell* |
| 叙事 | 机制深度 + 清晰逻辑链；「现象 → 机制 → 意义」 |
| 语气 | 直接、逻辑严密；Significance / Highlights 常单独提交 |
| Abstract | 结构化或单段视子刊；强调 novelty of mechanism |
| 标题 | 信息密度较高；关键分子/通路可出现在标题 |
| 图 | 主文图数量因子刊而异；Graphical Abstract 部分子刊需要 |

## Science 系

| 项目 | 要点 |
|------|------|
| 代表期刊 | *Science*, *Science Advances*, *Science Immunology* |
| 叙事 | 强调跨学科 interest 与 clear advance |
| 语气 | 紧凑；Abstract 常含 broader implication 句 |
| Abstract | ~125 words（*Science* 主刊常见）；一句点明 wider significance |
| 标题 | 短、有力；避免冗长从句 |
| 图 | Main + Supplementary 分明；Research Article vs Report 篇幅不同 |

---

## 三刊共通原则（generic-cns）

1. **Claim–Evidence–Boundary**：每段主张必须有证据；不越界推断
2. **首句承担功能**：段首句交代本段任务，非填充句
3. **动词优先**：show / demonstrate / reveal / suggest（非 prove 除非数学/形式证明）
4. **统计透明**：n、重复次数、检验方法、多重校正可定位
5. **避免 AI 味**：套话（「近年来」「随着…的发展」英译腔）、空洞 elevated 形容词

## 章节差异速查

| 章节 | Nature 偏重 | Cell 偏重 | Science 偏重 |
|------|-------------|-----------|--------------|
| Abstract | general interest 一句 | mechanism + finding | advance + significance |
| Intro | 漏斗：宽→窄→gap | gap + 本工作假设 | 问题 + 为何现在重要 |
| Results | 按故事线非实验顺序 | 逻辑递进、子图对应 | 简洁、少回溯 |
| Discussion | 不重复 Results | 机制延伸与限制 | broader impact |
