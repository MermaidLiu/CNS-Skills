# `cns-reviewer` 技能

[English](README_EN.md)

从 **Nature / Cell / Science** 审稿人视角模拟预投稿评审，输出三份 reviewer report 与编辑摘要。

## 适合用它做什么

- 投稿前自查创新性、机制链、统计与叙事
- 组会模拟审稿
- 预判 Major revision 风险点

## 典型请求

- 「按 Nature 审稿人标准评这篇摘要和图注。」
- 「模拟 Cell 投稿三轮 reviewer reports。」

## 你需要提供

- 目标期刊、稿件类型、摘要/图注/关键段落或全文

## 产出

- 3× reviewer report + editor summary + 作者行动清单

## 边界

- 非真实同行评议；不保证预测准确
- 返修信起草不在本 skill 默认范围

## 相关技能

- `cns-polishing` — 按意见改稿
- `cns-writing` — 补写薄弱环节
