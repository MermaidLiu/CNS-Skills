# `cns-reviewer` Skill

[中文说明](README.md)

Simulate pre-submission peer review from **Nature / Cell / Science** perspectives with three reviewer reports and an editor summary.

## What To Use It For

- Self-check novelty, mechanism, statistics, and narrative before submission
- Journal-club style mock review
- Anticipate major revision risks

## Typical Requests

- “Review this abstract and figure legends as a Nature referee.”
- “Simulate three Cell-style reviewer reports.”

## What You Need To Provide

- Target journal, article type, abstract/legends/key sections or full text

## Outputs

- Three reviewer reports, editor summary, prioritized author action list

## Boundaries

- Not a substitute for real peer review
- Rebuttal letters not included by default

## Related Skills

- `cns-polishing` — revise from feedback
- `cns-writing` — strengthen weak sections
